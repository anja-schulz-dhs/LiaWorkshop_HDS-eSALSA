## Worum geht es in diesen 10 Minuten?

> [!IMPORTANT]
> Bisher haben Sie LiaScript-Kurse **allein** bearbeitet — jede und jeder im eigenen Browser, das eigene Quiz, der eigene Lernstand.
>
> In einer Live-Veranstaltung möchten Lehrende aber oft wissen: *Wie hat die ganze Gruppe geantwortet?*
>
> - Wie bringe ich alle Teilnehmenden in **denselben** Kurs?
> - Was sehen die Lehrenden, was sehen die Lernenden?
> - Und was passiert dabei mit den Daten?

## Die Idee: Ein Kurs — viele Browser

                  {{0-1}}
********************************************

Ohne Klassenraum ist jeder Browser eine Insel:

```ascii

       LiaScript ist ein verteiltes System! Es gibt 
       keinen zentralen Server der Daten speichert!

  +-----------+        +-----------+        +-----------+
  | Browser A |        | Browser B |        | Browser C |
  |  Quiz: ✔  |        |  Quiz: ✘  |        |  Quiz: ✔  |
  +-----------+        +-----------+        +-----------+ 

        Niemand weiß, wie die anderen geantwortet haben.                                 .
```

********************************************

                  {{1}}
********************************************

Im Klassenraum werden die Browser miteinander **verbunden** — alle sehen dieselbe, **wahlweise anonyme oder persönliche** Auswertung:

```ascii
  +-----------+        +-----------+        +-----------+
  | Browser A |        | Browser B |        | Browser C |
  +-----+-----+        +-----+-----+        +-----+-----+
        |                    |                    |
        +--------------------+--------------------+
                             |
                    "Raum: LiaWorkshop"
                   (Relay, kein Speicher)
                             |
                             v
                  Quiz: ✔ 2x   ✘ 1x
```

********************************************

## Was wird geteilt — und was nicht?

| Im Klassenraum synchronisiert           | Darstellung                                    |
| --------------------------------------- | ---------------------------------------------- |
| **Quizze**                              | Wie viele haben richtig / falsch geantwortet?  |
| **Umfragen**                            | Verteilungen, Kategorien, Freitext-Sammlung    |
| **Ausführbarer Code**                   | gemeinsames Bearbeiten in Echtzeit             |
| **Chat**                                | versteht LiaScript — auch Quiz/Umfrage im Chat |

> [!TIP]
> Möchten Sie Klassenräume für einen Kurs ausschließen, genügt `classroom: disable` im Kopf der Datei. In SCORM-Exporten ist der Klassenraum standardmäßig aus und lässt sich mit `classroom: enable` einschalten.

## Jetzt Sie: Treten Sie dem Klassenraum bei!

                  {{0-1}}
********************************************

**So öffnen Lehrende einen Raum**

1. Kurs im Browser öffnen, oben rechts auf **Teilen** klicken.
2. **Klassenraum** wählen, einen Verbindungsdienst auswählen und einen **Raumnamen** vergeben.
3. **Verbinden** — die URL des Kurses ändert sich und enthält nun den Raum.
4. Diese URL (oder einen QR-Code daraus) an die Teilnehmenden geben.

## Zusammengefasst

> [!TIP]
> 1. **Ein Raum, viele Browser:** Die Teilnehmenden öffnen denselben Kurs über einen gemeinsamen Link.
> 2. **Keine neue Syntax:** Umfragen sind Quizze ohne Lösung.
> 3. **Anonym und ohne Server:** Nichts wird gespeichert — wer geht, nimmt seine Daten mit.
>
> Und wie bekommen Sie Ihr Material zu Ihren Studierenden? Darum geht es in der nächsten Phase: **Verbreiten**.
